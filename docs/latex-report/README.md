# Aegis report source

Compile from this directory with Tectonic:

```sh
tectonic --outdir ../../output/pdf main.tex
```

The report uses the screenshots in `screenshots/`. They were captured from the running local application using an isolated synthetic exercise database. No external image paths are required.

The presentation source is in `../presentation/build.mjs`. The completed submission files are under `output/` at the repository root.
